# D02-P14-T007 — Update application terminology and consolidate customer sidebar navigation

## Agent assignment

- Recommended tier: **FRONTIER** — this task requires scanning across multiple UI packages and frontend applications to rename hardcoded domain terms and fundamentally restructuring the routing/navigation hierarchy of the Customer Application sidebar.
- Work directly on `feat_delivery02_phase_14`; no child task branch.

## Requirements and rules

**Consumer-Friendly Lexicon Update:** Across both the public-web and customer-app, the internal business terminology must be updated to be more intuitive and relevant to end consumers.
- Update UI text, labels, and headings according to the following mapping:
  - `Sourced Vehicles` ➔ `My Vehicles`
  - `Reserved Vehicles` ➔ `Hold Vehicles`
  - `Invoice with PI` (Proforma Invoice) ➔ `Advanced Paid Vehicles`
  - `Invoiced Vehicles` ➔ `Purchased Vehicles`

**Sidebar Menu Consolidation:** The Customer Application sidebar currently contains too many discrete options.
- Reduce the top-level sidebar items to a maximum of **5 main items**.
- Logically group and integrate related sub-items (e.g., group all the renamed vehicle statuses—My Vehicles, Hold Vehicles, Purchased Vehicles—under a single parent menu like "My Garage" or "Purchases", group "Account Settings" with "Security", etc.).
