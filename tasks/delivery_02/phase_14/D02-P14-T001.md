# Delivery 02 - Phase 14 - Task 001

## Objective
Update the CarChief public app's "How to Buy" page to include detailed bank account information to protect customers from scams.

## Requirements
- Display USD and JPY account details for:
  - SUMITOMO MITSUI BANKING CORPORATION (SMBC)
  - MUFG Bank, Ltd.
- Display USD account details for ABU DHABI COMMERCIAL BANK (ADCB)
- Display PayPal payment instructions.
- **Dynamic Data**: Bank details must be fetched from the database via an API, as they are subject to change. Do not hardcode the details in the frontend.
- **Visuals**: Include the official bank logos for each bank.
- **Access Control**: Bank details must ONLY be visible to logged-in users. Do not show bank details to anonymous/unauthenticated users.
- Ensure the UI matches the CarChief design system and looks premium.

## Execution Plan
1. Add Bank Details to the database / mock API store (`apps/mock-api/src/store.ts`).
2. Create an API endpoint in the mock-api to fetch the bank details.
3. Update `HowToBuyExperience.tsx` (or a dedicated component) to fetch bank details from the API.
4. Implement an authentication check to hide the bank details section if the user is not logged in.
5. Add bank logos and apply enterprise typography, spacing, and styling in `how-to-buy.css`.
6. Verify rendering for both logged-in and anonymous users.
