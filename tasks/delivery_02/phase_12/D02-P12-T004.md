## Business-visible outcome

The public website no longer offers or advertises a demo account, and every account-related affordance points at the real registration and sign-in path.

## In scope

- Delete `apps/public-web/src/features/account-entry/components/DemoSignInPanel.tsx` and every demo label in `SessionStatusPanel.tsx` and `ReservationSignInGuidance.tsx`.
- Remove `signInDemo` from `apps/public-web/src/features/account-entry/hooks/useSession.ts` and the demo framing and `carchief.demoSession.v1` naming in `session-storage.ts`. Keep the open-redirect guard `resolveReturnTarget` and the expiry predicate.
- Replace the `/account` demo entry (`apps/public-web/src/app/account/**`, `AccountPageClient.tsx`, `AccountEntrySection.tsx`) with a page that directs the visitor to Register or to the Customer application sign-in, or remove the route and redirect it — whichever leaves no dead link from existing content.
- Remove the demo coupling in `apps/public-web/src/features/reservation/**` (`useReservation.ts`, `reservation-storage.ts`, `ReservationAction.tsx`) so a reservation requires a real session and presents an honest sign-in prompt when there is none.
- Remove demo copy in `apps/public-web/src/features/public-content/components/ContactPageContent.tsx` and `apps/public-web/src/app/search-showroom.tsx`.
- Remove the demo path from the legacy renderer `apps/public-web/src/server.ts` without breaking the tests that import it.

- Any change to the registration page delivered by `D02-P12-T003`.

- Deleting a component also deletes its stylesheet rules; leave no orphaned CSS in `account-entry.css` or `globals.css`.

## Contract and incremental mock work

No Mock API or OpenAPI change is owned. Every call to the removed `POST /api/v1/auth/demo-session` must be gone; a build-time search for `demo-session` under `apps/public-web` returns nothing.

### Frontend API integration

A reservation and any other authenticated public-web action must send the real bearer token from the stored session and render an honest sign-in prompt on 401. No public-web code path may mint a token locally.
