## Architectural boundaries and owned paths

- Owned paths: `apps/customer-app/src/features/account/**`, `apps/customer-app/src/features/shell/CustomerShell.tsx`, `CustomerShellProvider.tsx`, `CustomerNav.tsx` and their stylesheets and tests.

- The Service Worker must not cache any authentication request or response.

## Contract and incremental mock work

No Mock API or OpenAPI change is owned. Consume `AuthService.login`, `requestPasswordReset` and `confirmPasswordReset` from `D02-P12-T002`.

### Frontend API integration

Login posts through `AuthService.login` and stores the returned token for `HttpClientProvider`'s `getAuthToken` callback. A 401 renders the single generic invalid-credential message. A 400 with a `field` attaches to that input. A timeout or network failure renders a retryable error, never a silent failure. On sign-out the token and session are cleared from `sessionStorage` and any cached query data is discarded.
