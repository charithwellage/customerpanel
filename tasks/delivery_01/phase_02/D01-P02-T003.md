- Preserve accessibility, browser zoom, reduced motion, PWA safety and server-backed data behavior.

## Business-visible outcome

At first glance, the new Public Website looks and feels like the approved POC while retaining production-grade responsiveness, accessibility and swappable themes.

## In scope

- Correct the shared `carchief` semantic tokens to match the POC red/neutral/orange/green visual system and typographic hierarchy.
- Preserve `ocean` as a separately selectable secondary theme without duplicated feature components.
- Match the POC desktop shell: dark header, CarChief brand treatment, online indicator, uppercase navigation, orange active navigation treatment and outlined Customer Portal action.
- Match the POC hero: full-width dark photographic treatment, overlay/contrast, eyebrow label, large uppercase white/red/orange heading, supporting copy, primary/secondary actions and three-value proposition strip.
- Match the transition into the light showroom surface, existing search/filter preview, vehicle-card grid, image proportions, status badges, price/type hierarchy, borders, radii, spacing and shadows.
- Apply the same established POC language to Phase 1.2 promotional, buying-process, testimonial and FAQ preview sections already delivered.
- Build responsive phone/tablet adaptations that preserve content order, readable typography, touch targets and no horizontal overflow.
- Add a deterministic visual-regression baseline for the delivered Phase 1.2 screen at the reference width and representative responsive widths.

## Explicitly excluded

- Implementing Phase 1.3 search/filter behavior, external AI search, future content pages, new API contracts or fabricated POC records.
- Reproducing the POC's forced offline banner, unsafe SVG injection, disabled zoom, broad service-worker caching, inaccessible contrast or any known POC defect.
- Replacing the `ocean` theme with a copy of `carchief`.
- Pixel-forcing fixed desktop dimensions that break responsive layouts.
