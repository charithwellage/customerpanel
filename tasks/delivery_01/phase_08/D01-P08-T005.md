## The exact defect

`D01-P07-T002` (Phase 1.7) rewrote `apps/public-web/src/app/contact/page.tsx` wholesale to deliver the new `PUB-21` office-information content page. The pre-existing route at that merge base rendered `<Suspense><EnquirySection context={…}/></Suspense>` — the quotation/contact enquiry form delivered in an earlier phase (`PUB-13`, `PUB-15`, `PUB-34`) — and that rendering was deleted with no replacement. Consequences, verified live by the Phase 1.7 review's seventh pass:

- `EnquirySection` is rendered by no route in `apps/public-web/src`; it survives only in unit tests.
- `apps/public-web/src/features/vehicle-detail/VehicleDetailPage.tsx` and `apps/public-web/src/features/freight/FreightEstimateSection.tsx` still link visitors to `/contact?…`, which now has no form.
- 21 Playwright cases fail against the full suite (`enquiry-reservation.spec.ts`, `freight-enquiry.spec.ts`), confirmed on an isolated single-project re-run, not a parallel-worker artifact.

The Phase 1.7 phase review recorded this finding and, per an explicit product-owner decision, did **not** reopen `D01-P07-T002` a further time to fix it inline — Phase 1.7 was allowed to complete with this regression tracked as a deferred, non-blocking defect, to be corrected here instead.
