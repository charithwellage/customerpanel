## Business-visible outcome

Developers and reviewers can switch the same application screen between the POC theme and an alternate theme without changing feature code, while supervisors can see both styles running.

## In scope

- Add a typed theme registry containing `carchief` (default) and `ocean` (alternate).
- Add safe configuration/runtime selection with invalid-name fallback to `carchief`.
- Ensure all three application shells can consume either theme without feature-component changes.
- Add local-only switching or documented configuration, with production restricted to approved configuration.
- Persist only non-sensitive theme preference if runtime switching is implemented.
- Create/update root `DEVELOPER_USER_GUIDE.md` with theme selection, extension, testing and responsive/PWA instructions.
- Treat theme changes as presentation-only; API behavior, authorization, calculations and cache policy must not change.
