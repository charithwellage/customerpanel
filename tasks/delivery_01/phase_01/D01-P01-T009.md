## Business-visible outcome

A stable, navigable public application foundation and repeatable demo environment are ready for feature work.

## In scope

- Implement public layout, home skeleton, header, responsive menu, footer, not-found and error boundaries.
- Register the public PWA manifest/service worker with an offline shell, online/offline indicator and safe update prompt; do not cache sensitive or mock-authenticated data.
- Wire providers and the service boundary; show loading/empty/error feedback.
- Add basic semantic routes/metadata and ensure future private apps are planned for `noindex`.
- Add service-driven country/currency/language control slots and privacy/cookie-policy navigation. Until approved semantics exist, the controls must describe display-only behavior honestly.
- Use `docs/CarChief-Legacy-Public-Website-Audit.md` as visual/navigation evidence; retain essential mobile actions without inheriting the legacy dense layout or zoom restriction.

## Explicitly excluded

- Later-phase SEO policy details; this task provides semantic public routes, basic metadata and private-app `noindex` protection. Full public SEO is owned by Phase 1.8.

## Architectural boundaries and owned paths

Owned paths:

- `apps/public-web/src/app/**` shell routes/providers/layout
- `apps/public-web/src/components/layout/**`
