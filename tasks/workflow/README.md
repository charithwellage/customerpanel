# BA Workflow Follow-on Tasks

These tasks reconcile the BA workflow with the Customer and Salesperson applications after the management decisions in `tasks/DECISION_REGISTER.md` are resolved. They supplement, but do not replace, the application task sets. Do not begin implementation while a prerequisite decision is OPEN.

All tasks follow the common preflight, clean-tree, branch and execution-log rules in [`../SAMPLE_MASTER_PROMPT.md`](../SAMPLE_MASTER_PROMPT.md). They must update `TASK_EXECUTION_TRACKER.md` or the applicable delivery tracker, record tests, and report blockers explicitly.
