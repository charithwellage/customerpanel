- **Why**: this bug was already present before the out-of-band redesign touched this file (`git show <PR commit> -- .../VehicleCardPrimitive.tsx` confirms the redesign added `/allstock` as the new default `targetHref` but did not add the required client directive), so it is squarely this task's own owned defect, not a copy/route issue. Fixing it is required to bring `tests/e2e/public-content.spec.ts`'s Branch Hub test back to green and to stop a live production 500.
- **Investigated but reverted**: an initial attempt also added `'use client'` to `VehicleCollectionPrimitive.tsx`. That broke the opposite direction — `BranchPageContent.tsx` (still a Server Component) passes `getVehicleHref` as a plain function prop to `VehicleCollectionPrimitive`, which is legal server-to-server but not server-to-client (`"Functions cannot be passed directly to Client Components"`). Reverted: `VehicleCollectionPrimitive.tsx` stays a boundary-agnostic component (no directive), calling `getVehicleHref(vehicle)` itself and passing only the resulting string `actionHref` down to the now-client `VehicleCardPrimitive`, which is the correct minimal boundary.
