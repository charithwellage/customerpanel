Implemented the public content pages and regional branch hub routes for CarChief using a single shared presentational component, `ContentPageTemplate.tsx`.

Key features implemented:
- **Server Data Loaders (`apps/public-web/src/features/public-content/loadPublicContent.ts`)**:
  - `loadContentPages()`
  - `loadContentPageBySlug(slug)`
